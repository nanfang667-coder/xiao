# 每帖“已交定金，支持赔付”标识

管理员在“老师管理”的新增或编辑页面设置“显示已交定金，支持赔付标识”，保存后生效。开启时，首页、地区列表及全国推广卡片的右上角展示红底白字盾牌角标，正文留出顶部空间避免遮挡；关闭时完全隐藏并取消额外留白。

- `Teacher.supportsCompensation` 为布尔值，默认 `false`，历史帖子也默认隐藏。
- 仅管理员保存动作读取这个字段，且先执行身份校验。
- 团队表单不显示开关；团队投稿、审核更新及合作导入不会覆盖管理员设置。
- 此功能只控制展示，不提供自动赔付或赔付申请流程。
